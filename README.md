# TaskFlow - Application de Gestion de Tâches Avancée

Une application de gestion de tâches moderne, performante et intuitive construite avec JavaScript Vanilla, HTML5 et CSS3.

## ✨ Fonctionnalités

- **Architecture Modulaire** : Séparation claire des responsabilités (Logique, UI, Stockage).
- **Persistance** : Sauvegarde automatique dans le `LocalStorage`.
- **Gestion Avancée des Tâches** :
  - CRUD complet (Créer, Lire, Modifier, Supprimer).
  - Priorités (Basse, Moyenne, Haute).
  - Catégories personnalisées avec code couleur.
  - Dates d'échéance.
- **Organisation & Recherche** :
  - Recherche en temps réel.
  - Filtrage par statut (Toutes, Aujourd'hui, Terminées).
  - Filtrage par catégorie.
  - Tri (Plus récent, Plus ancien, Date d'échéance, Priorité).
- **Interface Interactive** :
  - **Drag & Drop** : Réorganisez vos tâches sans effort.
  - **Mode Sombre** : Transition fluide entre les thèmes clair et sombre.
  - **Suivi de Progression** : Statistiques en temps réel et barre de progression.
  - **Design Responsive** : Optimisé pour mobile et bureau.
- **Esthétique Moderne** : Design minimaliste inspiré de Notion et Trello.

## 🛠️ Stack Technique

- **HTML5** : Structure sémantique.
- **CSS3** : Propriétés personnalisées (variables), Flexbox, Grid et Animations.
- **JavaScript (ES6+)** : Logique modulaire sans frameworks externes.
- **Lucide Icons** : Iconographie propre et moderne.

## 🚀 Commencer

Ouvrez simplement `index.html` dans n'importe quel navigateur moderne. Aucun processus de construction ou d'installation n'est requis !

## 📁 Structure du Projet

```text
/
├── index.html      # Point d'entrée principal
├── css/
│   └── style.css   # Design moderne et animations
├── js/
│   ├── app.js      # Contrôleur principal & gestion des événements
│   ├── tasks.js    # Logique des tâches & statistiques
│   ├── ui.js       # Rendu DOM & gestion de l'UI
│   └── store.js    # Persistance LocalStorage
└── assets/         # Icônes et autres ressources
```
